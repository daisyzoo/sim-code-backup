# InternVLA-A1.5 离线训练环境（NVIDIA Driver 535）

这是独立的 InternVLA-A1.5 环境包，不与 FastWAM 环境混装。包内包含 Python 依赖 wheel 和项目代码快照，不包含数据集、预训练权重与训练输出。

要求：Linux x86_64、Python 3.10、NVIDIA 驱动 450.80.02 或更高。包内 PyTorch 为 2.7.1+cu118；目标机器的 535.104.12 驱动满足要求，宿主无需安装 CUDA Toolkit。

安装：

```bash
tar -xf InternVLA_env_py310_torch2.7.1_cu118_driver535_20260903_r2.tar
python3.10 -m venv --without-pip /path/to/internvla_venv
source /path/to/internvla_venv/bin/activate
cd InternVLA_env_py310_torch2.7.1_cu118_driver535_20260903_r2
bash install_into_active_venv.sh
python verify_environment.py --require-gpu
```

系统还需提供 FFmpeg 共享库。Ubuntu/Debian 通常执行：

```bash
apt-get update
apt-get install -y ffmpeg libavcodec-dev libavformat-dev libavutil-dev libswresample-dev libswscale-dev
```

兼容性说明：源训练环境使用 PyTorch 2.10+cu128，并包含为该 ABI 编译的 `flash-attn` 与 `causal-conv1d`。它们不能安全迁移到 535/cu118，因此本包没有混入这些二进制。项目代码在两处都有 PyTorch 回退：Wan attention 使用 scaled-dot-product attention，Qwen3.5 causal convolution 使用 `torch.nn.functional.conv1d`。`flash-linear-attention`/FLA 的 Triton 路径仍保留。该组合优先保证 driver 535 上可安装和可运行，训练速度和显存占用可能与本机 cu128 源环境不同。

安装脚本只写入当前已激活 venv；不会修改系统 Python、其他 venv 或宿主 CUDA。`--without-pip` 适用于没有 `ensurepip` 的精简容器；安装脚本会用包内 `pip` wheel 自动自举。已有可用 venv 时直接激活并安装即可。

Python 版本说明：项目的 `pyproject.toml` 声明 `requires-python = ">=3.10"`。本包已专门换成 CPython 3.10 wheel，并在全新的 Python 3.10 venv 中完成离线安装、依赖一致性、训练命令入口、InternVLAA15Policy 导入、CUDA 张量和 FLA Triton kernel 验证。个别依赖可能输出“推荐 Python 3.11”的提示，但不影响本项目在 Python 3.10 下运行。
