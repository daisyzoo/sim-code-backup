一、项目定位

SimFoundry 在本仓库中是一套「场景与机器人解耦」的仿真数据铸造链路： 用统一的 Scene Package 描述世界（桌面、包裹、背景），用独立的 Embodiment 描述 G1 23 DoF 本体与 Intel RealSense D435i 相机， 在 Isaac Lab 中采集与真机 teleop 对齐的 RGB + 关节轨迹，导出为 HuggingFace LeRobot 或 Unitree episode_XXXX 格式，供从零训练 VLA / WAM。

项目分两期推进：A 期用现成资产 / 手工 Real2Sim 先打通端到端； B 期再接视频→mesh→layout 的全自动 SimFoundry 重建链。 当前验收重心为独立分拣台场景（sorting_station_g1_23）。

二、整体架构

┌─────────────────────────────────────────────────────────────────────────┐ │ A 期（已通） B 期（接口预留） │ │ 手工 layout / YCB / 实拍贴图 → 视频 → Depth/SAM/Pose/Mesh → layout │ └───────────────────────────────┬─────────────────────────────────────────┘ ▼ scenes/<scene_id>/ （twin/layout.json + cousins/task/*.json） ▼ scene_bridge/ → USDA + Isaac spawn 配置 ▼ isaac_envs/ → G1 23DoF + D435i 640×480 ▼ collect_seed.py + quality_gate（分拣台） ▼ datasets/*.npz → unitree_json / lerobot_v21 导出 ▼ 从零 VLA / WAM 训练（ACT、Pi0、SmolVLA 等）

核心原则：换场景只换 scenes/<id>/ 目录，不改 env 与训练 dataloader 字段约定。
