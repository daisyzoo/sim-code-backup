# LIBERO / RoboCasa / LIBERO-Plus 开源评测对照

三者不是同一套评测的三个版本：

- **LIBERO** 测桌面知识迁移（空间 / 物体 / 目标 / 长程）
- **RoboCasa** 测厨房日常与长程组合（原子技能 vs 组合任务，厨房 / 物体 hold-out）
- **LIBERO-Plus** 在原版 LIBERO 上加压，拆开「饱和分数」背后的过拟合

数字来源：LIBERO 论文与官方仓库；RoboCasa RSS 2024 与 [robocasa.ai 1.0.1 文档](https://robocasa.ai/docs/build/html/benchmarking/benchmarking_overview.html)；LIBERO-Plus CVPR 2026 / [arXiv:2510.13626](https://arxiv.org/abs/2510.13626)。协议会随仓库版本变，**不要跨论文直接横比百分比**。

本目录另有一份可复现的官方场景评测 demo，见 [README.md](README.md)。

## 1. 三个关键数字

| 现象 | 数字 | 怎么读 |
|---|---|---|
| π0.5 在原版 LIBERO 平均成功率 | ~97% | 头部 VLA 已把原版 LIBERO 打满，单独报 95%+ 几乎不再区分模型 |
| GR00T N1.5 在 RoboCasa 未见组合任务 | 2.7% | 组合任务仍远未饱和，能拉开「会抓放」和「会做家务」 |
| LIBERO-Plus 改相机 / 机械臂初态 | 常从 95% 掉到 30% 以下 | 高分不等于可靠；固定观测下容易背轨迹 |

## 2. 总览对照

| 维度 | LIBERO | RoboCasa | LIBERO-Plus |
|---|---|---|---|
| 定位 | 终身学习 / 知识迁移 | 厨房泛化机器人 | VLA 鲁棒性诊断 |
| 发布 | NeurIPS 2023 | RSS 2024；评测栈现为 1.0 / 365 | CVPR 2026（arXiv 2025-10） |
| 仿真 | robosuite + MuJoCo 桌面 | robosuite 厨房全屋 | 沿用 LIBERO 环境 |
| 本体 | Franka Panda 固定基座 | Franka + 移动底盘 | 同 LIBERO |
| 任务规模 | 130 条语言条件任务 | 原版 100；365 版 65 原子 + 300 组合 | 10,030 条扰动实例 |
| 评测切分 | Spatial / Object / Goal / Long | Atomic-Seen / Composite-Seen / Unseen；pretrain vs target 厨房 | 7 维扰动 × L1–L5 难度 |
| 当前区分度 | 头部模型已饱和 | 组合任务仍很难 | 专门用来打饱和分 |

## 3. 各自评测场景

### 3.1 LIBERO：桌面四套件

语言指令桌面操作。任务模板来自 Ego4D，场景是厨房台面、客厅、书桌这类桌面布局，不是整间厨房走动。

| 套件 | 任务数 | 测什么 |
|---|---|---|
| Spatial | 10 | 物体集合固定，只改空间关系。例如两只一样的碗，把指定位置的那只放到盘子上 |
| Object | 10 | 技能几乎相同，目标物体换类别，测物体概念迁移 |
| Goal | 10 | 物体和摆放固定，只改目标（开抽屉、关炉、放进柜子），测程序性技能 |
| Long / LIBERO-10 | 10 | 从 100 任务里抽出的长程；LIBERO-90 多用作预训练，不计入常用 VLA 主表 |

社区默认协议：四套件各 10 episode，共 400 条；建议 3 个 seed 取平均。每任务另有 50 条遥操作演示。官方最小例子见仓库 README 的 Task 一节：取出任务 → 固定 init state → `OffScreenRenderEnv.step`。

### 3.2 RoboCasa：厨房日常

整间厨房：开门、开抽屉、旋钮、杠杆、按钮、插入、抓放，以及导航。复合任务按烧水、烤面包、泡咖啡、洗碗、收纳这类活动串技能。

- **原子任务**：单技能。原版 25 条覆盖 8 种基础技能；365 版扩到 65 条。
- **组合任务**：多技能长程。原版 75 条由 LLM 出蓝图再人工落地；365 版 300 条、60 类厨房活动。
- **场景切分**：原版约 10 种户型 × 多种风格（约 120 间厨房）。现行评测：2,500 间预训练厨房 vs 10 间 target 厨房，物体也 disjoint。

官方报告：每任务随机 50 条 rollout，二元成功。常见拆成 Atomic-Seen、Composite-Seen、Composite-Unseen；split 为 `pretrain` 或 `target`。v1.0.1 起 horizon 统一加长 1.5 倍。

### 3.3 LIBERO-Plus：七维扰动

任务语义仍是原版 LIBERO，不新增技能。把同一条任务沿 7 个可控轴生成变体，看模型是真会做，还是背住了固定相机、固定初态、固定摆放。

| 扰动轴 | 内容 |
|---|---|
| 物体布局 | 加干扰物，或平移 / 旋转目标 |
| 第三人称相机 | 位姿、朝向、视场 |
| 机械臂初态 | 起始关节 / 末端位姿 |
| 语言 | 改写、加复杂句；另有去指令、换目标对照实验 |
| 光照 | 强度、方向、颜色 |
| 背景纹理 | 桌面 / 场景材质 |
| 传感器噪声 | 抖动、高斯模糊 |

规模：10,030 条实例、21 个子维度；按若干代表模型的成功率分成 L1–L5。可自动生成约 56K 鲁棒性场景，用于训练或评测。

OpenVLA-OFT 在原版 LIBERO 上 97.1%，扰动后总分 69.6%。最脆的是机械臂初态（31.9%）和第三人称相机（56.4%）；背景（93.3%）和光照（88.7%）看起来稳，很大程度是因为腕部相机提供了近距几何。语言轴跌得少（79.5%）并不等于懂指令——去指令、换目标实验里，模型常仍执行原任务。

## 4. 优缺点

| 基准 | 适合回答的问题 | 优点 | 缺点 |
|---|---|---|---|
| LIBERO | 算法是否跟上公开 VLA 数字？空间 / 物体 / 目标 / 长程哪一类先崩？ | 协议统一、LeRobot 等栈现成；四套件把知识类型拆开；算力便宜、可复现；论文数字可对表 | 桌面固定基座，无走动、少电器关节；视觉偏 MuJoCo；相机 / 光照 / 初态几乎固定，易背轨迹；头部模型已饱和；VLA 论文多用多任务 SFT，很少跑原版终身学习协议 |
| RoboCasa | 会不会做厨房长程？换厨房、换物体还能否做？原子技能和组合技能差多远？ | 场景和技能更接近家务；有 seen/unseen 任务与厨房 hold-out；视觉更写实；组合任务仍能拉开模型；有仿真+真机共训证据 | 计算和 horizon 重；厨房域窄；组合任务成功率低、方差大；协议从 100 任务演进到 365、horizon 还改过；本体是 Franka+底盘，不是人形；LLM 蓝图任务语义有时别扭 |
| LIBERO-Plus | 高分是不是过拟合固定观测？换相机、换初态、换摆放还会不会做？语言是不是摆设？ | 直接接在 LIBERO checkpoint 上；七轴可定位失败模式；L1–L5 能看崩溃阈值；专门针对已饱和的公开数字 | 技能集合没有变，仍是桌面 MuJoCo；扰动是合成的，不等于真实厨房多样性；1 万条实例评测贵；难度档由标定模型的正确率划分，可能绑死那几家模型；语言改写 alone 测不出是否真跟指令 |

## 5. 三者互补，不要互相替代

**建议怎么用**

- 需要对齐 OpenVLA / π0 / π0.5 论文：跑 LIBERO 四套件，当回归基线，不要当能力上限。
- 桌面分已经很高：加 LIBERO-Plus 的相机、机械臂初态、布局三轴。这三轴最能揭开「背演示」。语言轴要配去指令和换目标，不能只看改写后分数还高。
- 目标是厨房台面 / 家务长程：RoboCasa 的原子 vs 组合、seen vs unseen、pretrain vs target 厨房，比 LIBERO 更接近问题本身。组合-未见任务现在仍接近地板，适合当压力测试，不适合当唯一 KPI。

**对本仓库仿真线的含义**

工作区里的厨房台 + G1 双臂，和 RoboCasa 的任务语义最近，但本体、相机、控制频率都对不上，数字不能直接引用当自家分数。

LIBERO / LIBERO-Plus 适合当算法对照和过拟合探针：同一套抓放，故意改第三人称相机和手臂初态，就能知道采集是否把策略锁死在固定视角。

若自建评测，建议同时保留三件事：

1. 任务语义切分（物体 / 空间 / 目标 / 长程）
2. 场景与物体 hold-out（RoboCasa 那套）
3. 观测扰动（LIBERO-Plus 那套）

只报一条平均成功率，三个基准各自踩过的坑都会再踩一遍。
